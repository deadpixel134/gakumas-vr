# Gakumas VR

학원 아이돌마스터 DMM판을 위한 비공식 Meta Quest/OpenXR VR 모드 프로젝트입니다.

이 저장소에는 VR 런타임 소스, 설정·설치 프로그램, 테스트와 기술 문서만 포함합니다. 게임 원본 파일, Localify 한글 패치, 사용자 설정, 로그, 롤백 데이터와 빌드 산출물은 포함하지 않습니다.

- 프로젝트 개요 및 개발 방법: [`vrmod/README.md`](vrmod/README.md)
- 현재 상태: [`docs/GAKUMAS_VR_STATUS.md`](docs/GAKUMAS_VR_STATUS.md)
- 설계 문서: [`docs/GAKUMAS_VR_DESIGN.md`](docs/GAKUMAS_VR_DESIGN.md)
- 마일스톤: [`docs/VR_MILESTONES.md`](docs/VR_MILESTONES.md)
- 변경 기록: [`vrmod/CHANGELOG.md`](vrmod/CHANGELOG.md)

> 이 프로젝트는 비공식 팬 프로젝트이며 게임 개발사 및 배급사와 관련이 없습니다. 모드를 사용하려면 사용자가 정식으로 설치한 게임이 필요합니다.
