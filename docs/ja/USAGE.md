# 使い方と操作方法

[プロジェクトホーム](../../README.ja.md) · [インストール](INSTALLATION.md) · [構成](ARCHITECTURE.md)

## 表示モード

- **3D環境:** ゲーム世界を両眼VRで表示します。左手の補助パネルは初期状態でOFFで、左Gripで切り替えます。
- **完全な平面画面:** 黒いVR空間の正面にゲーム画面を自動表示します。このメインパネルはGripでは消せません。
- **切り替え:** 3Dを離れると正面パネルが自動で戻り、3Dに入るとステレオ世界へ戻ります。
- **手元パネルの表示条件:** ONでも、パネル側の手がHMDの視野内にあるときだけ表示します。視野外ではパネルのコピーと送信処理も停止します。

## デフォルト操作

| 操作 | デフォルト入力 |
|---|---|
| カーソルを合わせる | 右コントローラーのaim ray |
| クリック／長押しドラッグ | Aボタンまたは右Trigger |
| 戻る | Bボタン（`Esc`） |
| スクロール | 右Thumbstick上下 |
| 3D補助パネルON/OFF | 左Grip |

Triggerを引く動きで細かな照準がずれる場合はAボタンがおすすめです。Triggerは押し始めの座標を先に固定し、長押しして一定距離を移動した場合だけドラッグになります。直接タッチには対応していません。

デフォルトでは、ゲームウィンドウがWindowsの最前面にあるときだけ入力します。マウスや通常のゲーム入力もそのまま利用できます。

## ボタン名

- **Primary Face:** 右手ではA、左手ではX
- **Secondary Face:** 右手ではB、左手ではY

設定でパネル側とポインター側の手を入れ替えた場合、この名称も選択した手に従います。

## 設定ツール

インストール後に`ゲームフォルダー\vrmod\tools\GakumasVR.Configurator.exe`を実行します。上部で韓国語・英語・日本語を選択できます。

- **レンダー:** 片目ごとのレンダー倍率0.50～2.00、ワールドの目の間隔倍率
- **VFX:** 承認済みデフォルト、すべてON、すべてOFF、手動設定
- **パネル:** パネル／ポインターの手、開始状態、位置・サイズ・回転、プレイヤー向き、切替ボタン
- **入力:** クリック／戻るボタン、Triggerクリック、スクロールと感度、ゲームフォーカスの要求

ゲームを終了した状態で保存してください。不正な値は安全なデフォルト値に置き換えられ、理由がログに記録されます。

## レンダー倍率とフレームレート

片目ごとのレンダー倍率は3Dステレオだけに適用され、正面／手元パネルの元解像度には影響しません。1.00より大きい値はスーパーサンプリングで、設定ツールに性能警告が表示されます。縦横の両方に適用されるため、2.00は1.00の約4倍のピクセルを描画します。

測定例では、異なるステレオペアが約59.14組/秒、OpenXR送信が平均114.79fps・中央値117.60fpsでした。後者には同じゲームフレームをHMD周期に合わせて再送信する回数が含まれ、ゲームが毎秒120種類の画面を描画するという意味ではありません。

## 既知の制限

- SteamVRとMeta Quest Linkはまだ実機未確認です。
- 直接タッチには対応していません。
- 1.00を超えるレンダー倍率は使用できますが、実機での性能・安定性確認は残っています。
- ゲーム更新でUnityやレンダー構造が変わると、一部の3D場面が平面パネルへフォールバックする場合があります。
