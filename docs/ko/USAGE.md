# 사용 방법과 조작법

[프로젝트 홈](../../README.md) · [설치 방법](INSTALLATION.md) · [프로그램 구조](ARCHITECTURE.md)

## 화면 표시 방식

- **3D 환경:** 게임 세계를 양안 VR로 표시합니다. 왼손 패널은 기본적으로 꺼져 있으며 왼손 Grip으로 켜거나 끕니다.
- **완전한 평면 화면:** 검은 VR 공간의 시야 정면에 게임 화면이 자동으로 표시됩니다. 이 주 패널은 Grip으로 끌 수 없습니다.
- **전환:** 3D를 벗어나면 정면 패널이 자동 복귀하고, 다시 3D로 들어가면 스테레오 세계로 전환됩니다.
- **왼손 패널 가시성:** 패널을 켜도 패널 손이 HMD 시야 안에 있을 때만 표시됩니다. 손을 시야 밖으로 옮기면 렌더 복사와 제출도 멈춥니다.

## 기본 조작

| 동작 | 기본 입력 |
|---|---|
| 커서 조준 | 오른손 컨트롤러의 aim ray |
| 클릭·누른 채 이동 | A 버튼 또는 오른쪽 Trigger |
| 뒤로 가기 | B 버튼 (`Esc`) |
| 3D 이동 | 오른쪽 Thumbstick, 현재 시야의 상하 각도 포함 |
| 시야 회전 | 왼쪽 Thumbstick, 기본 30° 스냅 턴 |
| 3D 보조 패널 ON/OFF | 왼손 Grip |

A 버튼은 트리거를 당길 때 생기는 미세한 조준 흔들림을 피하고 싶은 경우에 권장합니다. 트리거는 누르기 시작한 위치를 먼저 고정해 오조작을 줄이며, 길게 누르고 일정 거리 이상 이동하면 드래그로 전환됩니다. VR 환경에서는 스틱 스크롤을 사용하지 않습니다. 직접 터치는 현재 지원하지 않습니다.

기본 설정에서는 게임 창이 Windows 포그라운드일 때만 입력을 주입합니다. 마우스와 기존 게임 입력은 그대로 사용할 수 있습니다.

## 버튼 이름

- **Primary Face:** 오른손은 A, 왼손은 X
- **Secondary Face:** 오른손은 B, 왼손은 Y

패널 손과 포인터 손을 설정에서 바꾸면 같은 의미가 선택한 손의 버튼에 적용됩니다.

## 설정 프로그램

설치 후 `게임 폴더\vrmod\tools\GakumasVR.Configurator.exe`를 실행합니다. 상단에서 한국어·영어·일본어를 선택할 수 있습니다.

- **렌더:** 눈별 렌더 배율 0.50~2.00, 월드 눈 간격 배율
- **VFX:** 승인 기본값, 전체 켜기, 전체 끄기, 수동 설정
- **패널:** 패널 손·포인터 손, 시작 상태, 위치·크기·회전, 플레이어 방향 정렬, 토글 버튼
- **입력:** 클릭·뒤로 버튼, 트리거 클릭, 이동 손, 이동 속도, 스냅/연속 회전, 스냅 각도, 게임 포커스 요구

라이브 6DoF는 기본으로 켜져 있고 라이브 연출 카메라와 독립된 진입 anchor를 사용합니다. 기본 이동 손은 오른손이며 반대 손인 왼손이 시야 회전을 담당합니다. 이동 속도 기본값은 1.95m/s입니다. 이동 손을 왼손으로 바꾸면 두 역할이 자동으로 교체됩니다. 스냅 기본값은 30°이며 15°/30°/45°/60° 중 선택할 수 있습니다. 스틱 회전은 화면 roll을 만들지 않고, VR 진입 후 HMD를 실제로 옆으로 기울인 변화만 roll로 반영합니다. 자세한 구현 계약은 [VR 조작·포즈 합성 명세](VR_INTERACTION_SPEC.md)를 참고하십시오.

설정은 게임을 종료한 상태에서 저장하십시오. 잘못된 값은 안전 기본값으로 대체되고 로그에 사유가 기록됩니다.

## 렌더 배율과 성능

눈별 렌더 배율은 3D 스테레오 렌더에만 적용되고 정면·손 패널의 원본 해상도에는 영향을 주지 않습니다. 1.00보다 큰 값은 슈퍼샘플링이며 설정 프로그램이 성능 경고를 표시합니다. 가로·세로를 함께 배율하므로 2.00은 1.00 대비 약 4배의 픽셀을 렌더합니다.

성능 측정에서 게임 속도 스테레오는 약 59.14쌍/초, OpenXR 제출은 평균 114.79fps·중앙값 117.60fps였습니다. 후자는 같은 게임 프레임을 HMD 주기에 맞춰 재제출하는 횟수를 포함하므로 서로 다른 게임 장면을 초당 120개 렌더한다는 뜻은 아닙니다.

## 알려진 제한

- SteamVR와 Meta Quest Link 경로는 아직 실기 미검증입니다.
- 직접 터치는 지원하지 않습니다.
- 1.00을 넘는 렌더 배율은 허용되지만 실기 성능·안정성 검증은 남아 있습니다.
- 게임 업데이트로 Unity 또는 렌더 구조가 바뀌면 일부 3D 문맥이 평면 패널로 폴백할 수 있습니다.
