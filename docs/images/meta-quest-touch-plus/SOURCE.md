The artwork is used to identify Meta Quest 3 Touch Plus controllers in the user manual. It is not covered by this repository's MIT license. It does not imply Meta sponsorship, partnership, or endorsement. The localized guide layout, labels, and mod bindings are provided by Gakumas VR. The controller drawings are the official Meta PNG, cropped into left/right views and scaled proportionally; they have not been redrawn or generated with AI.

Regenerate the three annotated guides on Windows with Pillow installed:

```powershell
python vrmod/scripts/Render-ControllerGuides.py
```
