## 한국어

- **Quest 3 공식 컨트롤러 이미지:** 한국어·영어·일본어 컨트롤 안내를 Meta Quest Hardware Art 1.8의 Touch Plus 공식 그림으로 교체했습니다. 원본 이미지와 출처·사용 조건도 함께 제공합니다.
- **조작 안내 보완:** Grip(옆쪽 중지 버튼)과 Trigger(앞쪽 검지 버튼), 양손 스틱 역할·클릭, 패널 짧게 누르기와 VR 설정 길게 누르기를 구분했습니다. 상하·미세 이동용 오른손 월드 그립과 캐릭터 접촉 최초 동의도 설명합니다.
- **오프라인 안내 포함:** 배포 ZIP의 `docs/CONTROLLER-GUIDE.md`에서 세 언어 안내와 이미지를 열 수 있습니다. GitHub README의 컨트롤 이미지도 상세 조작 문서에 연결됩니다.
- **전체 기능 유지:** 접촉·변형·흔들림·햅틱·표식과 설정을 포함합니다. 최초 안내문을 끝까지 읽고 1회 동의하기 전에는 접촉 반응이 차단됩니다. 동의 기록은 배포하지 않습니다.
- **기존 사용자:** 설정 GUI의 업데이트 확인 또는 새 ZIP의 설치기로 업데이트할 수 있습니다. 기존 설정·Localify 보존, 릴리스 노트 미리보기와 DMM 게임 경로 자동 탐색을 유지합니다.

이 릴리스는 이미지·문서·배포 안내를 갱신합니다. 런타임 조작은 v0.178.3과 같으며, 버전 표기만 변경합니다. 컨트롤러 그림의 기종은 Quest 3이며 새로운 Quest 3 실기 검증을 의미하지 않습니다.

## English

- **Official Quest 3 controller artwork:** Korean, English, and Japanese control guides now use Meta's Touch Plus drawing from Meta Quest Hardware Art 1.8. The original image, source details, and supplied terms are included.
- **Clearer controls:** distinguishes side Grip/middle finger from front Trigger/index finger, both sticks and their clicks, short panel presses, and long VR-settings presses. Explains right-hand World Grip for vertical/fine movement and first-use contact consent.
- **Offline guides:** open `docs/CONTROLLER-GUIDE.md` in the release ZIP for all three languages and diagrams. README controller images link to the detailed guides.
- **Full feature set retained:** includes contact, deformation, jiggle, haptics, markers, and settings. Reactions are blocked until the user reads the notice to the end and gives one-time consent. No consent record is shipped.
- **Existing users:** update through the configurator or the new ZIP's installer. Existing settings/Localify preservation, release-note previews, and automatic DMM game-folder detection remain available.

This release updates artwork, documentation, and bundled guides. Runtime controls match v0.178.3; only version identifiers change. Using Quest 3 artwork does not imply new Quest 3 hardware validation.
