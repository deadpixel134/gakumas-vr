# Gakumas VR v0.174.0

[한국어](#한국어) | [English](#english) | [日本語](#日本語)

## 한국어

v0.174.0은 v0.173에서 실기 승인된 6DoF·roll 격리 구조를 유지하면서 기본 조작값을 조정한 정식 릴리스입니다.

- 라이브 독립 6DoF를 기본으로 활성화
- 스냅 턴 기본값을 15°에서 30°로 변경
- 이동 속도 기본값을 1.50m/s에서 1.95m/s로 변경(정확히 1.3배)
- 15°/30°/45°/60° 선택, smooth 회전, 손 역할 교환과 physical HMD roll 보존은 그대로 유지
- 설정 GUI의 한국어·영어·일본어 안내와 기본값 복원 동작 갱신

기존 `vrmod/config/settings.json`은 업데이트 시 보존됩니다. 따라서 이미 저장한 값을 그대로 쓰려면 아무 작업도 필요 없고, 새 기본값 전체를 적용하려면 설정 프로그램에서 **기본값**을 불러온 뒤 저장하십시오.

이번 릴리스는 기본값 변경에 대한 자동 테스트·빌드·패키지 검증을 통과했으며, 별도 v0.174 VR 실기는 아직 진행하지 않았습니다. 핵심 6DoF와 roll 격리 동작의 실기 기준은 v0.173입니다.

## English

v0.174.0 is a stable release that keeps the 6DoF and roll-isolation behavior hardware-approved in v0.173 while revising product defaults.

- Independent live 6DoF is enabled by default
- Default snap turn changes from 15° to 30°
- Default movement speed changes from 1.50m/s to 1.95m/s (exactly 1.3×)
- 15°/30°/45°/60° choices, smooth turning, hand swapping, and physical HMD roll preservation remain available
- Korean, English, and Japanese configurator text and default restoration are updated

Updates preserve an existing `vrmod/config/settings.json`. Existing saved values therefore remain unchanged. To apply the complete new profile, load **Defaults** in the configurator and save.

This release passed automated tests, builds, and package validation for the default changes. A separate v0.174 VR hardware run has not yet been performed; v0.173 remains the hardware baseline for the underlying 6DoF and roll-isolation behavior.

## 日本語

v0.174.0は、v0.173で実機確認された6DoFとroll分離の動作を維持し、製品デフォルトを変更した正式リリースです。

- 独立ライブ6DoFをデフォルトONに変更
- スナップターンのデフォルトを15°から30°へ変更
- 移動速度のデフォルトを1.50m/sから1.95m/sへ変更（正確に1.3倍）
- 15°/30°/45°/60°、スムーズ回転、左右交換、実際のHMD roll保持は継続
- 韓国語・英語・日本語の設定表示とデフォルト復元を更新

更新時は既存の`vrmod/config/settings.json`を保持するため、保存済みの値は変わりません。新しいプロファイル全体を適用する場合は、設定ツールで**初期値**を読み込み、保存してください。

このリリースはデフォルト変更に関する自動テスト・ビルド・パッケージ検証を通過しています。v0.174としての追加VR実機テストはまだ行っておらず、基礎となる6DoFとroll分離の実機基準はv0.173です。
