## 한국어

- **게임 설치 경로 자동 탐색:** 인스톨러가 DMM에 등록된 학원마스 설치 경로를 불러옵니다. 여러 경로는 목록에서 선택하며, 자동 찾기와 수동 선택을 함께 제공합니다. 직접 입력한 경로는 탐색 결과로 덮어쓰지 않습니다.
- **업데이트 전 릴리스 노트:** 설정 GUI에서 새 정식 버전을 찾으면 GUI 언어에 맞는 변경 사항을 최대 5개까지 표시합니다. 업데이트 / 나중에를 선택하고 전체 GitHub 릴리스 노트도 열 수 있습니다. 게임 실행 중에는 설치할 수 없습니다.
- **사용 안내 정리:** GitHub 기본 README를 영어로 바꾸고 큰 언어 선택 링크, 설치·업데이트·실행·조작 안내와 컨트롤 이미지를 정리했습니다. 한국어·일본어 문서도 제공합니다.
- **전체 기능 빌드:** 손 표시, 캐릭터 접촉 충돌, 본 변형·흔들림, 접촉 햅틱·표식과 관련 설정을 모두 포함합니다. 캐릭터 접촉은 최초 1회 안내문을 끝까지 읽고 동의해야 활성화됩니다. 동의 전에는 이전 설정이 켜져 있어도 반응을 차단하며, 동의 기록은 패키지에 포함하지 않습니다.
- **기존 사용자:** 현재 GUI의 자동 업데이트 또는 새 ZIP의 설치기로 같은 게임 폴더를 업데이트할 수 있습니다. 릴리스 노트 미리보기는 v0.178.3 GUI로 업데이트한 뒤부터 사용할 수 있습니다. 기존 사용자 설정과 Localify는 보존됩니다.

빌드·자동 테스트 126개·패키지 199개 파일 해시, 신규 설치·제거 및 Localify 보존 검사와 실제 DMM 경로 조회·GUI 자동 입력을 확인했습니다. 이 릴리스의 사용자 PC 게임·VR 실기는 아직 수행하지 않았습니다.

## English

- **Automatic game-folder detection:** the installer reads the Gakumas location registered with DMM. Multiple installations appear in a list, with Auto-detect and Browse available. Detection preserves a manually entered path.
- **Release notes before updating:** when the configurator finds a new stable version, it shows up to five changes in the GUI language. Choose Update / Later or open the full GitHub release notes. Installation is blocked while the game is running.
- **Clearer usage guides:** English is now the default GitHub README, with larger language links, installation/update/launch/control instructions, and controller diagrams. Korean and Japanese guides remain available.
- **Full-feature build:** includes hand display, character contact collision, bone deformation/jiggle, contact haptics/markers, and their settings. Contact requires one-time consent after reading the notice to the end. Reactions remain blocked before consent even with previously enabled settings. No consent record is shipped.
- **Existing users:** update through the current GUI or install the new ZIP into the same game folder. Release-note previews become available after updating to the v0.178.3 GUI. Existing settings and Localify are preserved.

Builds, 126 automated tests, 199 package file hashes, clean install/uninstall and Localify preservation, and real DMM-path discovery/GUI autofill have been checked. User PC gameplay and VR hardware testing of this release have not been performed.

## 日本語

- **ゲームフォルダーの自動検出:** インストーラーがDMMに登録された学マスのインストール先を読み込みます。複数ある場合は一覧から選択でき、自動検出と手動の参照にも対応します。手動入力したパスは上書きしません。
- **更新前のリリースノート:** 設定GUIで新しい正式版を検出すると、GUIの言語に合わせて変更点を最大5件表示します。更新／後でを選べ、GitHubの全文も開けます。ゲーム実行中はインストールできません。
- **使い方の整理:** GitHubの標準READMEを英語に変更し、大きな言語リンク、インストール・更新・起動・操作の説明とコントローラー図を追加しました。韓国語・日本語の案内も利用できます。
- **全機能ビルド:** 手の表示、キャラクターとの接触判定、ボーン変形・揺れ、接触ハプティクス・マーカーと関連設定をすべて含みます。接触機能は初回に案内を最後まで読んで同意する必要があります。同意前は以前の設定が有効でも反応を遮断します。同意記録はパッケージに含みません。
- **既存ユーザー:** 現在のGUIの自動更新、または新しいZIPのインストーラーで同じゲームフォルダーを更新できます。リリースノートのプレビューはv0.178.3のGUIへの更新後から利用できます。既存の設定とLocalifyは保持します。

ビルド・自動テスト126件・パッケージ199ファイルのハッシュ、新規インストール・削除とLocalify保護、および実際のDMMパスの検出・GUIへの自動入力を確認しました。このリリースのユーザーによるPCゲーム・VR実機テストは未実施です。
