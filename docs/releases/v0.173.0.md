# Gakumas VR v0.173.0

[한국어](#한국어) | [English](#english) | [日本語](#日本語)

## 한국어

v0.173.0은 설정·설치·자동 업데이트와 범용 6DoF 조작을 사용자 VR 실기로 확정한 첫 정식 기준 릴리스입니다.

주요 변경:

- 비-live 3D 장면 positional 6DoF, 설정 선택형 live 독립 6DoF
- 기본 왼손 월드축 시야 회전, 오른손 최종 시야 기준 완전 3D 이동; 설정에서 좌우 교환
- 기본 15° 스냅 턴과 15°/30°/45°/60° 또는 부드러운 회전
- 스틱·scene 회전의 roll을 제거하고 실제 HMD roll 변화만 보존
- 한국어 기본의 한국어·영어·일본어 설정 GUI
- 수동 VFX, eye render scale 0.50~2.00과 고배율 경고
- clean install, Localify 공존, manifest 기반 안전 제거·rollback
- GitHub stable Release 확인 및 ZIP/SHA-256 검증 자동 업데이트

설치:

1. `GakumasVR-v0.173.0.zip`을 내려받아 별도 폴더에 압축을 풉니다.
2. 게임을 완전히 종료합니다.
3. `GakumasVR.Installer.exe`를 실행하고 게임 폴더를 선택합니다.
4. 설정은 설치된 `vrmod/GakumasVR.Configurator.exe`에서 변경합니다.

Meta Quest 2 + Virtual Desktop OpenXR에서 실기 확인했습니다. SteamVR OpenXR와 Meta Quest Link/Air Link는 예비 지원이며 아직 이 프로젝트에서 실기 확인하지 않았습니다. 직접 터치와 live 좌상단 시계 회귀는 이번 완료 범위에서 제외했습니다.

## English

v0.173.0 is the first stable baseline whose configuration, installation, secure update flow, and general 6DoF controls have all been approved in user VR hardware testing.

Highlights:

- Positional 6DoF in non-live 3D scenes and optional independent live 6DoF
- Left-stick world-axis view turning and right-stick full-3D final-view locomotion by default, with swappable hands
- 15° snap turn by default; 15°/30°/45°/60° or smooth turning
- No roll from scene or stick rotation; only the user's physical HMD roll delta is preserved
- Korean-default Korean/English/Japanese configurator
- Manual VFX controls and eye render scale 0.50–2.00 with a high-scale warning
- Clean installation, Localify coexistence, manifest-owned uninstall, and rollback
- GitHub stable Release update checks with ZIP/SHA-256 verification

Install by extracting the ZIP, closing the game, and running `GakumasVR.Installer.exe`. Configure the installed mod with `vrmod/GakumasVR.Configurator.exe`.

Hardware validation used Meta Quest 2 with Virtual Desktop OpenXR. SteamVR OpenXR and Meta Quest Link/Air Link remain preliminary and untested by this project. Direct touch and the live upper-left clock regression check were excluded from this completion scope.

## 日本語

v0.173.0は、設定・インストール・安全な自動更新・汎用6DoF操作をユーザーのVR実機テストで確認した最初の正式基準リリースです。

主な変更:

- 非ライブ3Dのpositional 6DoFと、設定で有効にできる独立live 6DoF
- デフォルト左スティックのワールド軸視点回転、右スティックの最終視線基準フル3D移動。左右交換可能
- デフォルト15°のスナップターン。15°/30°/45°/60°またはスムーズ回転
- scene／スティック由来のrollを除去し、実際のHMD roll変化のみ保持
- 韓国語を既定にした韓国語・英語・日本語設定GUI
- 手動VFX、eye render scale 0.50～2.00、高倍率警告
- clean install、Localify共存、manifest所有ファイルのみの削除とrollback
- GitHub stable Release確認とZIP/SHA-256検証による自動更新

ZIPを展開し、ゲームを完全に終了してから`GakumasVR.Installer.exe`を実行してください。設定はインストール先の`vrmod/GakumasVR.Configurator.exe`で変更できます。

Meta Quest 2＋Virtual Desktop OpenXRで実機確認済みです。SteamVR OpenXRとMeta Quest Link/Air Linkは予備対応で、本プロジェクトでは未検証です。直接タッチとlive左上時計の回帰確認は今回の完了範囲から除外しました。
